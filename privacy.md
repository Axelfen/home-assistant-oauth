# Privacy Policy

This Google OAuth client, named "Home Assistant" in the Google Cloud project "Home Assistant Google", is used by one person only: its owner. It lets the owner's own self-hosted Home Assistant server read and write the owner's own Google Calendar events and Google Tasks.

**What is accessed:** calendar events and task lists of the owner's Google account, only after the owner signs in and grants access.

**Where the data goes:** it is stored only on the owner's private Home Assistant server on their home network. It is not sold, not shared with third parties and not used for advertising. When the owner asks their voice assistant about their calendar or tasks, the relevant details are passed to that assistant to answer the question.

**Revoking access:** the owner can revoke access at any time at https://myaccount.google.com/permissions.

**Contact:** open an issue on this repository.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
